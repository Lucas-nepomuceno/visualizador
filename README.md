# Como rodar a aplicação

1. No VSCode, clone o repositório.
2. Com o Python instalado, ative a sua venv.
3. Para baixar as dependências, use `pip install requirements.txt` na pasta do seu repositorio clonado
4. Rode a aplicação usando `python main.py`

# Funcionalidades

Este projeto oferece uma interface simples e interativa para aplicar as seguintes transformações em imagens:

- **Redimensionamento da imagem**  
  Permite ajustar o tamanho da imagem manualmente.

- **Escala de Cinza**  
  Converte a imagem colorida para tons de cinza.

- **Inversão de cores**  
  Inverte as cores da imagem, gerando um efeito negativo.

- **Detecção de bordas**  
  Aplica um filtro que destaca os contornos presentes na imagem.

- **Desfoque (Blur)**  
  Permite aplicar um nível ajustável de desfoque à imagem.

- **Nitidez**  
  Aumenta a nitidez da imagem para realçar detalhes.

- **Contraste**  
  Ajusta o contraste da imagem para intensificar as diferenças entre luz e sombra.

- **Rotação**  
  Gira a imagem em um ângulo entre 0 e 360 graus.

# Limitações

&emsp; Não é possível redimensionar uma imagem para um tamanho maior que o seu original
